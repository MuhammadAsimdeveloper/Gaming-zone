## Verification notes

- GitHub repository metadata (existence, language, SPDX license, archived status, last push) was read from the public GitHub API on 2026-11-02.
- `trigger-rally/trigger-rally` and `3dcity/3dcity` returned 404 and are **not** listed as verified repositories.
- `mozilla/BrowserQuest` is archived/deprecated; its LICENSE carries MPL-2.0 for code and CC-BY-SA 3.0 for content.
- `Hextris/hextris` is GPL-3.0 despite GitHub reporting `NOASSERTION`; the license file was read.
- `luanti-org/luanti` is LGPL for code and CC-BY-SA 3.0 for media; media reuse needs separate care.
- `acherm/fifacher` and `RenderBr/mineralic` have no license file; treat as all-rights-reserved until clarified.
- Cloudflare Pages free-tier limits found on the official page: 500 builds/month, 1 concurrent build, 20,000 files, 25 MiB per file. Bandwidth and request limits were **not** stated on that page and are treated as unverified.
- GitHub Free documents unlimited public and private repositories and "$12 USD of included compute usage per month"; a "2,000 Actions minutes" figure was not stated on the pages checked.
